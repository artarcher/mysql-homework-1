1. Конспект занятия №1: Создание таблиц, наполнение и выборка

1.1. Базовые понятия

  • База данных (БД) — упорядоченное хранилище информации в виде связанных таблиц. В отличие от файлов Excel, БД выдерживает миллионы одновременных пользователей без зависаний и потерь.
  • СУБД MySQL — программа-сервер («робот-кладовщик»), которая физически управляет файлами базы данных, обеспечивает безопасность и выполняет наши запросы.
  • SQL [Эс-Кью-Эль] — язык структурированных запросов, команды на котором мы отправляем роботу MySQL.

1.2. Анатомия таблицы и типы данных

  • Столбцы (поля) — характеристики (названия пишем латиницей: full_name, course).
  • Строки (записи) — конкретные анкеты студентов/записи.
  • INT [инт] — тип данных «целое число» (1, 2, 2500).
  • VARCHAR(N) [вАр-чар] — строка переменной длины (текст), где N — максимальное число символов.
  • PRIMARY KEY [прАймари ки] — «первичный ключ». Столбец (обычно id), гарантирующий уникальность каждой строки (как номер паспорта).
  • AUTO_INCREMENT [Ауто инкримЕнт] — автоматическая нумерация: база сама ставит номер 1, 2, 3... при добавлении новой строки.
  • NOT NULL [нот нал] — запрет оставлять поле пустым.
  • DEFAULT значение [дифОлт] — значение по умолчанию, если поле не заполнили при вставке.

1.3. Базовые команды занятия №1

1. Создание таблицы: CREATE TABLE [криЭйт тЭйбл]

CREATE TABLE students (
    id INT PRIMARY KEY AUTO_INCREMENT,
    full_name VARCHAR(100) NOT NULL,
    group_name VARCHAR(20) NOT NULL,
    course INT DEFAULT 1,
    scholarship INT DEFAULT 0
);

2. Добавление данных: INSERT INTO ... VALUES [инсЁрт Инту ... вЭльюс]
Правило: текст всегда пишем в одинарных кавычках 'Текст', числа — без кавычек.

INSERT INTO students (full_name, group_name, course, scholarship) 
VALUES ('Смирнов Алексей', 'ИС-101', 1, 2500);

-- Можно добавлять несколько строк сразу через запятую:
INSERT INTO students (full_name, group_name, course, scholarship) VALUES
('Козлова Мария', 'ДЗ-102', 1, 3500),
('Волков Дмитрий', 'ИС-201', 2, 4000);

3. Выборка данных: SELECT [селЕкт], фильтрация WHERE [вэа], сортировка ORDER BY [Ордэр бай]

-- Выбрать всё из таблицы (звёздочка * означает "все столбцы"):
SELECT * FROM students;

-- Выбрать только студентов 1 курса со стипендией больше 2000:
SELECT full_name, scholarship FROM students WHERE course = 1 AND scholarship > 2000;

-- Отсортировать по стипендии от максимума к минимуму (DESC):
SELECT * FROM students ORDER BY scholarship DESC;

2. Конспект занятия №2: Изменение, удаление, умный поиск и статистика

2.1. Изменение данных: UPDATE ... SET ... WHERE [апдЭйт ... сэт ... вэа]

Команда обновляет информацию в уже существующих строках. Критически важно: всегда указывать WHERE id = .... Если забыть WHERE, база обновит абсолютно все строки в таблице! 

-- Назначить студенту с id = 1 стипендию 3000 рублей:
UPDATE students 
SET scholarship = 3000 
WHERE id = 1;

-- Изменить группу и курс одновременно (через запятую):
UPDATE students 
SET group_name = 'ИС-201', course = 2 
WHERE id = 1;

2.2. Удаление строк: DELETE FROM ... WHERE [дилИт фром ... вэа]

Полностью стирает строку из таблицы. Если не написать WHERE, таблица очистится целиком! 

-- Отчислить (удалить) студента с id = 3:
DELETE FROM students 
WHERE id = 3;
Почему AUTO_INCREMENT не возвращает старые номера?
Если удалить строку с id = 3, следующий новый студент получит номер 4, а не 3. Удалённые номера никогда не используются повторно, чтобы не привязать к новому человеку старые архивные записи или долги прежнего владельца номера.

2.3. Поиск по кусочку текста: LIKE [лайк] и знак %

Знак процента % заменяет любое количество любых символов:

-- Найти студентов, чья фамилия НАЧИНАЕТСЯ на 'Смирнов':
SELECT * FROM students WHERE full_name LIKE 'Смирнов%';

-- Найти группы, содержащие буквы 'ИС' в любом месте:
SELECT * FROM students WHERE group_name LIKE '%ИС%';

2.4. Агрегатные функции (считаем за бухгалтерию)

  • COUNT(*) [кАунт] — считает общее число строк.
  • SUM(столбец) [сам] — складывает все числа в столбце.
  • AVG(столбец) [Эй-ви-джИ] (Average) — вычисляет среднее арифметическое.
  • MIN(столбец) / MAX(столбец) — находит минимальное и максимальное значение.
-- Посчитать сумму всех стипендий и количество студентов:
SELECT COUNT(*), SUM(scholarship), AVG(scholarship) FROM students;

3. Конспект занятия №3: Связи между таблицами (FOREIGN KEY, JOIN) и GROUP BY

3.1. Почему нельзя хранить всё в одной таблице?

Если хранить название отделения и ФИО куратора прямо в таблице студентов, эти длинные строки придётся копировать сотни раз. При смене куратора придётся переписывать 30 строк. Поэтому данные разделяют на две таблицы: в главной таблице хранят информацию об отделении/группе, а у студента записывают лишь короткую цифру — group_id.

3.2. Внешний ключ: FOREIGN KEY ... REFERENCES [фОрин ки ... рЭференсес]

Это ограничение-замок. Оно запрещает записать студенту несуществующий номер группы и не позволяет случайно удалить группу, пока в ней учатся студенты. 

-- Главная таблица: Список групп
CREATE TABLE groups_list (
    id INT PRIMARY KEY AUTO_INCREMENT,
    group_name VARCHAR(20) NOT NULL,
    curator VARCHAR(100) NOT NULL
);

-- Зависимая таблица со связью FOREIGN KEY:
CREATE TABLE students (
    id INT PRIMARY KEY AUTO_INCREMENT,
    full_name VARCHAR(100) NOT NULL,
    group_id INT,
    FOREIGN KEY (group_id) REFERENCES groups_list(id)
);

3.3. Склейка таблиц: JOIN ... ON [джойн ... он]

Команда JOIN склеивает две таблицы при выводе на экран. Точка означает принадлежность: имя_таблицы.имя_столбца. 

SELECT students.full_name, groups_list.group_name, groups_list.curator
FROM students
JOIN groups_list ON students.group_id = groups_list.id;

Как читать строку ON: «Склей строки там, где номер группы у студента (students.group_id) в точности равен паспорту группы (groups_list.id)».

3.4. Группировка: GROUP BY [груп бай]

Собирает строки в категории (корзинки) и применяет функции COUNT или SUM к каждой корзинке отдельно: 

-- Посчитать, сколько студентов учится в каждой группе по отдельности:
SELECT group_id, COUNT(*) 
FROM students 
GROUP BY group_id;

4. Практическое домашнее задание: «Деканат колледжа»

Вам необходимо написать единый SQL-скрипт, содержащий последовательное выполнение всех пунктов ниже.

Шаг 1. Создание двух связанных таблиц

  1. Создайте главную таблицу отделений departments:
    • id — INT PRIMARY KEY AUTO_INCREMENT;
    • department_name — VARCHAR(100) NOT NULL (название отделения, например: «Информационные технологии»);
    • head_of_department — VARCHAR(100) NOT NULL (ФИО заведующего отделением).
  2. Создайте зависимую таблицу учебных групп college_groups:
    • id — INT PRIMARY KEY AUTO_INCREMENT;
    • group_code — VARCHAR(20) NOT NULL (шифр группы, например: «ИС-101»);
    • students_count — INT DEFAULT 0 (число студентов);
    • course_num — INT DEFAULT 1 (номер курса);
    • department_id — INT, связанный внешним ключом FOREIGN KEY с полем id таблицы departments.

Шаг 2. Заполнение таблиц данными (INSERT)

  1. Добавьте в таблицу departments 3 разных отделения колледжа.
  2. Добавьте в таблицу college_groups минимум 5 групп, указав для каждой соответствующий department_id (1, 2 или 3).

Шаг 3. Модификация и удаление (UPDATE, DELETE)

  1. Напишите запрос UPDATE, который переводит одну конкретную группу (по её id) на следующий курс (course_num = course_num + 1).
  2. Напишите запрос UPDATE, который меняет число студентов (students_count) в одной из групп. Обязательно укажите WHERE id = ....
  3. Напишите запрос DELETE FROM, который удаляет одну конкретную группу по её id.

Шаг 4. Выборки и отчёты (SELECT, LIKE, JOIN, GROUP BY)

  1. Напишите запрос с оператором LIKE, который находит все группы, чей шифр начинается на буквы 'ИС%'.
  2. Напишите запрос со склейкой JOIN, который выводит читаемый сводный отчёт: шифр группы, курс, название отделения и ФИО заведующего отделением (без числовых id).
  3. Напишите запрос, выводящий все группы, отсортированные по убыванию числа студентов (ORDER BY students_count DESC).
  4. Напишите аналитический запрос с группировкой GROUP BY department_id, который считает: сколько всего групп на каждом отделении (COUNT(*)) и сколько суммарно студентов там учится (SUM(students_count)).
